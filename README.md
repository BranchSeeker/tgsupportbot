# TG VPN Support Bot (aiogram)

Простой Telegram-бот поддержки для VPN-сервиса на `aiogram`:

- пользователи создают тикеты;
- если проблема «не работает», бот уточняет приложение и платформу (Android/iPhone);
- админ/владелец получает уведомление и может закрывать тикеты.

## Быстрый старт

1. Скопируйте переменные окружения:

```bash
cp .env.example .env
```

2. Заполните `.env` (**обязательно**):

- `BOT_TOKEN`
- `OWNER_ID`
- `ADMIN_IDS` (через запятую)

3. Запуск:

```bash
docker compose up --build -d
```

4. Логи:

```bash
docker compose logs -f support_bot
```

## Команды

### Для пользователей

- `/start` — приветствие и кнопка создания тикета.
- `/ticket` — создание тикета вручную.
- `/mytickets` — список ваших тикетов.

### Для админов

- `/tickets` — открытые тикеты.
- `/close <ticket_id>` — закрыть тикет.

Также админ может закрыть тикет кнопкой в уведомлении.

## Хранение данных

Используется SQLite-файл `tickets.db` внутри контейнера.
